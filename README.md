# Intercon Pharma Website

A clean, modern pharmaceutical company website with Tailwind CSS styling.

## 🚀 Quick Start

Simply open `index.html` in your browser. No build process needed!

## 🌐 GitHub Pages Deployment

### Step-by-Step:

1. **Create GitHub repository:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/intercon-pharma.git
   git push -u origin main
   ```

2. **Enable GitHub Pages:**
   - Go to repository Settings → Pages
   - Source: `main` branch, `/ (root)` folder
   - Click Save

3. **Your site will be live at:**
   `https://YOUR_USERNAME.github.io/intercon-pharma/`
